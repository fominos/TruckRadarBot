# TruckRadarBot
TruckRadarBot is an internal automation tool developed for the TrackRadar logistics platform. This Telegram bot streamlines communication and data management between dispatchers and managers, creating a seamless workflow for processing freight transportation orders.

The project involves the development of a sophisticated Telegram bot utilizing the ConversationHandler for managing multi-step conversations. It serves as a bridge between the familiar Telegram interface and powerful Google Workspace tools, ensuring efficient data flow and document management. All information received from dispatchers is automatically transmitted to a Google Sheets table, while files are stored in Google Drive. Managers process the data in the table and add relevant files, which are then returned to the dispatchers.
